# Increase Unit Test Coverage

## Objective
Identify areas in the `kthena/` codebase with low unit test coverage and add comprehensive unit tests to improve reliability. The goal is to contribute over 500 lines of code.

## Requirements
- Identify packages in `kthena/pkg/` or other critical directories with missing or low test coverage.
- Implement unit tests to cover various scenarios, including edge cases.
- Ensure all tests pass.
- Follow existing testing patterns in the codebase.
